# Study Buddy Planner

This repository contains a local snapshot of the StudyBuddy Android project adapted for a planner-focused workflow.

## Overview

This project provides a mobile study planning experience with task management, reminders, and organization features for students.

## Getting started

1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the app on an Android device or emulator.
